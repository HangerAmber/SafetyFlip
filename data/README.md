# Data contracts and availability

`examples.jsonl` contains **two authored illustrative fixtures**. They exercise both reversal directions and safe responses on both sides. Their scores and boolean validator judgments are synthetic test inputs. They are not generated by Qwen, are not sampled from the paper's data, and must not be used as a benchmark or reported as construction-quality measurements.

The original 8,000 accepted pairs and 500-pair internal diagnostic split are **forthcoming**. Exact seed provenance, candidate generation traces, taxonomy, split manifest and deduplication decisions are also forthcoming. The paper uses both “8k examples” and “8k pairs”; batch units need the original manifest.

Each JSONL record has `schema_version`, `pair_id`, `provenance`, `semantic_frame_id`, `original`, `flipped`, and `validation`. Unknown fields and wrong types are rejected. `pair_id` is unique. Keep both sides in the same split; a shared seed or frame may require additional grouping when the full dataset is released.

Each side records the instruction, independently obtained `analysis` (`label`, `annotation`), and `response` (`text`, `behavior`). Instruction labels are `Safe` or `Unsafe`; response behavior is `Comply`, `Refuse`, or `Pivot`. The boundary annotation is exactly `r_frame`, `r_crit`, `r_policy`. Frame fields capture domain, entities, task form, style, constraints and recoverable benign utility. These are compact non-operational fields, not free-form chain-of-thought.

Validation requires preservation **strictly greater than 0.8**, inverted instruction labels, annotation/response behavior consistency, and safe responses on both sides. `source` identifies `synthetic_fixture`, `human_audit`, or `teacher_validator`. Data checks trust the recorded judgments; they do not evaluate actual text safety or semantic equivalence. A real provider needs a disclosed validation process. Synthetic judgments are accepted only for illustrative fixtures.

`safetyflip.schema.serialize_target` defines this reference implementation's joint annotation-plus-response target as stable compact JSON. Prompt and padding tokens are masked from CE and KL. This serialization and KL scope are documented implementation choices; the original template, tokenizer handling and response-only inference bridge remain forthcoming.

The smoke configuration supplies stable manual shortcut and semantic class labels, ordered as all original sides followed by all flipped sides. Semantic labels match across each pair. The toy classes are not Safe/Unsafe labels and are not the original unavailable ontologies; the two toy assignments coincide numerically and cannot establish disentanglement.

From the repository root:

```console
python -m safetyflip validate data/examples.jsonl
python -m safetyflip demo --data data/examples.jsonl
```
